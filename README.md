# Otoder
Bu depo, WordPress 6.8.3 için geliştirilen **Otoder Auto Marketplace** temasını ve kurulum/toplayıcı eklentisini içerir.

- Tema dosyaları `car-marketplace-theme/` klasöründedir ve arabam.com / sahibinden.com benzeri ücretsiz otomobil ilan deneyimi sağlar.
- Kurulum ve otomasyon eklentisi `plugins/otoder-essentials/` klasöründedir; gerekli sayfa/kategori tohumlamasını ve ilan toplayıcıyı içerir.

Kullanım ve kurulum talimatları için ilgili klasörlerdeki README dosyalarına bakın.

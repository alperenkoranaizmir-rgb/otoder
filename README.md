# Otoder

Bu depo, WordPress 6.8.3 için geliştirilen **Otoder Auto Marketplace** temasını içerir. Tema dosyaları `car-marketplace-theme/` klasöründedir ve arabam.com / sahibinden.com benzeri ücretsiz otomobil ilan deneyimi sağlar.

Kullanım ve kurulum talimatları için tema klasöründeki README dosyasına bakın.
